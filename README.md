# PhishTrace 🔍

**A Chrome extension that analyzes website URLs for suspicious phishing indicators.**

PhishTrace is a browser-based security project designed to help users identify potentially suspicious websites through local URL analysis and heuristic-based detection.

## ✨ Features

- URL risk scoring (0–100)
- LOW, MEDIUM and HIGH risk classification
- Lookalike domain detection
- Brand impersonation checks
- Suspicious keyword detection
- IP address-based URL detection
- Unicode and punycode warnings
- Domain structure analysis
- Detailed scan findings

## 🛠️ Technologies

- HTML
- CSS
- JavaScript
- Chrome Extensions Manifest V3

## 🚀 Installation

1. Download or clone this repository.
2. Extract the project files.
3. Open Google Chrome.
4. Visit `chrome://extensions`.
5. Enable Developer mode.
6. Select **Load unpacked**.
7. Choose the folder containing `manifest.json`.

## 🔎 How It Works

PhishTrace analyzes the current website URL using locally implemented detection rules and heuristic checks. It assigns a risk score based on suspicious indicators and displays the findings in its popup interface.

## ⚠️ Limitations

PhishTrace is an experimental educational project.

- It cannot guarantee that a website is safe.
- It may produce false positives or miss phishing websites.
- Its detection rules are not a replacement for professional security tools.

Always verify website addresses before entering sensitive information.
